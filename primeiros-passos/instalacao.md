# 📦 Instalação & Requisitos

{% hint style="info" %}
Escolha um launcher abaixo para instalar o modpack **Sitrus Cobblemon**. No celular (Android), use as abas **Mojo** ou **Zalith** e instale a versão **MOBILE**.
{% endhint %}

<a href="https://cmpaixao.github.io/sitrus-cobblemon-wiki/static/download-launcher.html" class="button primary" data-icon="download">Baixar Launcher da Sitrus</a> <a href="https://discord.gg/pGdzZAYCCs" class="button secondary" data-icon="discord">Discord da Sitrus</a>

O launcher oficial do PC é o [**Sitrus Launcher**](https://github.com/cmpaixao/sitrus-launcher). O botão **sempre baixa a última versão**. Dúvidas de instalação? Chame no [Discord](https://discord.gg/pGdzZAYCCs).

{% tabs %}
{% tab title="Sitrus Launcher" %}
## Sitrus Launcher (oficial)

O [Sitrus Launcher](https://github.com/cmpaixao/sitrus-launcher) instala o pack **Sitrus Cobblemon** (Minecraft 1.21.1 + Fabric).

{% stepper %}
{% step %}
### Baixe o instalador

Baixe a última versão no GitHub (o botão consulta a release mais recente):

<a href="https://cmpaixao.github.io/sitrus-cobblemon-wiki/static/download-launcher.html" class="button primary" data-icon="download">Baixar última versão</a>

Se o download automático não abrir, use a [página de releases](https://github.com/cmpaixao/sitrus-launcher/releases/latest) e pegue o `Sitrus-Launcher-Setup`.
{% endstep %}

{% step %}
### Instale o launcher

Execute o instalador `Sitrus-Launcher-Setup` baixado e conclua a instalação no Windows.
{% endstep %}

{% step %}
### Abra e jogue

Abra o **Sitrus Launcher**, entre na sua conta e inicie o pack. O launcher já aponta para o Sitrus Cobblemon.
{% endstep %}
{% endstepper %}
{% endtab %}

{% tab title="SKLauncher" %}
## ![SKLauncher](<../.gitbook/assets/01 (8).png>) Como Instalar o Modpack Pelo SKLauncher

{% stepper %}
{% step %}
### Baixe o Aplicativo do SKLauncher

Baixe o arquivo de instalação no site oficial do [SKLauncher](https://skmedix.pl/downloads).
{% endstep %}

{% step %}
### Instale o SKLauncher

Abra o arquivo do SKLauncher e instale-o completamente.

Verifique se seu launcher está em **Inglês** ou **Português**!
{% endstep %}

{% step %}
### Localizando o Modpack da Sitrus

Após entrar na sua conta do SK (**Modo Offline**), vá em **Gerenciar Instalações** » **Modpacks** » **Modrinth** e digite `Sitrus Cobblemon`.
{% endstep %}

{% step %}
### Instalando o Modpack

Clique no modpack da **Sitrus Cobblemon** e selecione **Instalar última versão**. Aguarde o modpack instalar.
{% endstep %}

{% step %}
### Prontinho!

Após finalizar a instalação, o modpack já estará pronto para o uso!
{% endstep %}
{% endstepper %}
{% endtab %}

{% tab title="Modrinth" %}
## ![Modrinth](<../.gitbook/assets/02 (4).png>) Como Jogar Pelo Modrinth

{% stepper %}
{% step %}
### Baixe o Aplicativo do Modrinth

Baixe o arquivo de instalação no site oficial do [Modrinth](https://modrinth.com/app).
{% endstep %}

{% step %}
### Instale o Modrinth

Abra o arquivo do Modrinth e instale-o no seu computador.
{% endstep %}

{% step %}
### Busque o Modpack da Sitrus Cobblemon

Clique na opção da **bússola** para buscar e pesquise `Sitrus Cobblemon` para encontrar o modpack do servidor.
{% endstep %}

{% step %}
### Instale o Modpack

Ao lado do modpack da **Sitrus Cobblemon**, clique em **Install**.
{% endstep %}

{% step %}
### Inicie o Modpack

Uma nova opção com a logo do servidor aparece no aplicativo do Modrinth. Clique nela e depois em **Play** para iniciar o jogo e logar na sua conta do Minecraft.
{% endstep %}
{% endstepper %}

{% tab title="Mojo" %}
## ![Mojo Launcher](<../.gitbook/assets/03 (3).png>) Como Instalar o Modpack Pelo Mojo Launcher

{% hint style="warning" %}
⚠️ **Nota:** disponível **apenas para Android**.
{% endhint %}

{% stepper %}
{% step %}
### Baixe o Aplicativo do Mojo Launcher

Baixe o arquivo de instalação no site oficial do [MojoLauncher](https://github.com/MojoLauncher/MojoLauncher/releases).
{% endstep %}

{% step %}
### Instale o Mojo Launcher

Abra o APK do Mojo Launcher e instale-o em seu celular.

Verifique se seu launcher está em **Inglês** ou **Português**!
{% endstep %}

{% step %}
### Logando no seu launcher

Ao abrir o Mojo, ele pede uma opção de login. Selecione **Local Account** para jogar no modo offline.

Se você tiver uma conta original, entre pela **Microsoft**.
{% endstep %}

{% step %}
### Localizando o Modpack da Sitrus

No menu inicial do Mojo, clique na **seta para cima** (ao lado do lápis), na parte inferior.

Clique em **Criar nova instância** / **Create new instance**.

Selecione **CREATE MODPACK INSTANCE** e pesquise `Sitrus Cobblemon MOBILE`.
{% endstep %}

{% step %}
### Instalando o Modpack

Clique no modpack da **Sitrus Cobblemon MOBILE** (ele tem a foto cinza).

Se você instalar o modpack de **PC** no celular, ele pode não abrir corretamente.
{% endstep %}

{% step %}
### Prontinho!

Depois da instalação, volte à tela inicial. O modpack já estará pronto para o uso.

Lembre-se de selecionar o **modpack correto** antes de jogar.
{% endstep %}
{% endstepper %}

### Instalando Bibliotecas

Ao abrir o Zalith, ele pede para instalar bibliotecas para o launcher abrir. Aperte em **Concordar e instalar**.

### Localizando o Modpack da Sitrus

No menu inicial do Zalith, clique no **ícone de download** (ao lado da engrenagem), na parte superior.

No lado esquerdo, clique em **Baixar Modpack**.

Troque a plataforma para **Modrinth** e pesquise `Sitrus Cobblemon`.
{% endstep %}

{% step %}
### Instalando o Modpack

Clique no modpack da **Sitrus Cobblemon MOBILE** (ele tem a foto cinza).
