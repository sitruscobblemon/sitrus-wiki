# 🧭 Comandos & Atalhos

{% hint style="info" %}
Atalhos padrão do **Cobblemon** e comandos do Sitrus. Se alguma tecla não responder, abra **Opções → Controles → Teclas** e procure a categoria Cobblemon — outro mod pode estar usando a mesma tecla.
{% endhint %}

## 🎮 Teclas e Controles Padrão

| Tecla                        | Função                | Descrição                                                                                                 |
| ---------------------------- | --------------------- | --------------------------------------------------------------------------------------------------------- |
| `M`                          | **Sumário / Inicial** | Abre o sumário do time (status, golpes, IVs, EVs e item). Sem inicial, abre a tela de escolha do starter. |
| `R`                          | **Lançar / Recolher** | Envia ou recolhe o Pokémon selecionado na barra da equipe. Olhando para um selvagem, inicia batalha.      |
| `↑` / `↓`                    | **Trocar Pokémon**    | Muda o slot selecionado na equipe.                                                                        |
| `R` + `Scroll`               | **Ciclar a equipe**   | Segure `R` e role o mouse para passar pelos Pokémon da party.                                             |
| `O`                          | **Ocultar equipe**    | Mostra ou esconde a barra da party na tela.                                                               |
| `Shift` + **Clique Direito** | **Roda de interação** | Item, ombro, montaria e outras ações no Pokémon solto.                                                    |
| `Alt Esquerdo`               | **Olhar na montaria** | Segure para olhar livremente enquanto cavalga.                                                            |

{% hint style="warning" %}
A tecla do **sumário é `M`**, não `B`. No celular, reatribua `M` nas teclas do launcher.
{% endhint %}

## ✨ Lista de Comandos

| Comando                    | Função                                                                   |
| -------------------------- | ------------------------------------------------------------------------ |
| `/menu`                    | Abre o menu principal do servidor.                                       |
| `/warps`                   | Abre a lista de warps.                                                   |
| `/kits`                    | Abre os kits para resgate.                                               |
| `/spawn`                   | Volta ao spawn.                                                          |
| `/explorar`                | Teleporta para um local aleatório do Overworld, fora da região do spawn. |
| `/carteira`                | Mostra o seu dinheiro.                                                   |
| `/pay <jogador> <quantia>` | Transfere dinheiro para outro jogador.                                   |
| `/tpa <jogador>`           | Pede teleporte até outro jogador.                                        |
| `/tpacancel`               | Cancela o pedido de teleporte enviado.                                   |
| `/tpaccept`                | Aceita um pedido de teleporte recebido.                                  |
| `/tpahere <jogador>`       | Pede para o outro jogador vir até você.                                  |
| `/flan menu`               | Abre o menu da Flan (use **dentro** da sua claim).                       |
| `/raidglobal`              | Abre o menu da [Raid Global](../cobblemon-and-guias/raids.md).           |
| `/gts`                     | Abre o Global Trade Station.                                             |
| `/sts`                     | Abre o Server Trade Station.                                             |
