# 🏆 **Ranqueada Sitrus Cobblemon**

{% hint style="warning" %}
Olá Treinador, pelo visto você se interessou em participar das batalhas ranqueadas da **Sitrus Cobblemon**. Pois bem, saiba que a ranqueada não é um local de se brincar… Até temos filas casuais feitas para jogadores que querem batalhar sem perder pontos, porém o mundo das ranqueadas é muito diferente de tudo que você já vivenciou.
{% endhint %}

## Como participar?

Para você participar das Ranqueadas deverá ir até a **Arena Ranqueada** utilizando uma Waystone e buscar pelo **Gerente da Ranqueada**.

-   Ao interagir com ele, você conseguirá escolher entre as filas **Casuais** e **Ranqueadas**.
-   Após isso é só entrar na fila e aguardar até achar um oponente.
-   Para sair da fila, basta refazer os passos.

{% hint style="info" %}
Alguns comandos, como /Enderchest são bloqueados ao entrar na ranqueada.

Voce não conseguirá iniciar uma ranqueada carregando itens de uso manual, como poções, waystone, ou shulkerbox.

Após entrar na fila, não recomendamos o jogador ir fazer outra coisa, apenas aguardar a partida.

Não inicie partidas Ranqueadas, enquanto estiver assistindo outra batalha pelo comando /spectatebattle.
{% endhint %}

## Missões

Existem dois tipos de missões: as **Diárias** e as **Semanais**.

-   As diárias resetam sempre às **00:00**.
-   Já as semanais resetam às **00:00 de Segunda**.
-   O menu de missões poderá ser acessado no **Menu Casual**.
-   As missões contam para ambos os formatos, Casual e Ranqueados.

## Recompensas

As recompensas ranqueadas são dadas àqueles que se destacam jogando e se dedicando a se tornar o melhor jogador do servidor! Verifique o NPC **Gerente da Ranqueada** para mais detalhes.

As recompensas são divididas em dois tipos:

-   **Recompensas Finais:** entregues aos jogadores ao finalizar a ranqueada.
-   **Marcos:** entregues aos jogadores que alcançarem aquele marco, seja subindo de Elo ou Ranking.
